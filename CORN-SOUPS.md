# Creamy Corn Soup — Profile Matrix

The "creamy corn soup" lineage is a family of seven flavour profiles sharing a common base (corn + onion + garlic + stock, all pressure-cooked together with a legume cooked pot-in-pot). Each profile adds its own spices, umami stack, acid, and legume choice.

This file documents the 7-profile matrix at reference level. Specific cooked iterations live in their own recipe files; this doc cross-references and tracks which profiles have been built, cooked, and rated.

> **Migrated from legacy PDF source** (`corn-soup-flavor-profiles.pdf`). All quantities are for a **2 kg corn base** (scaled for family of five). Cooked recipes in the project may use scaled-down versions (e.g. the Japanese recipe is at 1.5 kg corn).

---

## Shared base (constant across profiles)

| Component | Amount |
|:----------|-------:|
| Frozen corn (partially thawed) | 2000 g |
| Onions, diced | 4 large |
| Garlic | 100 g (~16 cloves) |
| Stock cubes + water | 6 cubes + 2000 ml water |
| Legume (dried, pot-in-pot, no soak) | per profile — see below |

**Stock split (per source PDF):** 3 cubes + 1000 ml water with corn, 3 cubes + 1000 ml water with legumes (cooked pot-in-pot). The migrated West African recipe consolidates this; either approach works.

**Profile-specific alternative vegetables** are added per profile and shape the dish identity beyond the base flavouring.

> **Note on bean form divergence:** the matrix below specifies **dried legumes** for all profiles. Several cooked recipes have diverged from this:
> - **Mexican** main recipe uses **tinned kidney beans (4 × 400 g)** instead of dried 250 g
> - **Mexican Low-Effort** uses **dried butter beans (300 g)** — different legume entirely
> - **West African** main recipe uses dried black-eyed beans matching matrix
>
> The matrix represents original design intent; recipe files represent actual cooks. When in doubt, follow the recipe file.

## How to use this matrix

1. **For an unbuilt profile** (Thai, Mediterranean): use the profile's ingredient list as the spec, design method by analogy to the cooked Japanese/Nordic/W.African/Indian/Mexican recipes, then write a new `creamy-corn-soup-{profile}.md` file when committing to cook.

2. **For an already-built profile**: defer to the recipe file. The matrix shows the design intent; the recipe file shows what's actually cooked.

3. **Lara/Jannes/Anja preference flags** noted in profile sections highlight where the matrix conflicts with established preferences. Substitute or omit when cooking for the full family.

4. **Predicted scores** are useful only directionally. Update RATINGS.md with actuals as profiles get cooked; over time the predicted-vs-actual delta becomes a calibration signal for future profile design.

5. **When recipe diverges from matrix** (different bean form, additional vegetables, different acid handling), the recipe file wins for cooking. The matrix is preserved as historical design intent.
