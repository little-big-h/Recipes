# Supergreen (Singapore) — menu ingredient & nutrition reference

Source: https://www.supergreen.sg/menu (ingested 2026-09-29). This is a
build-your-own salad-bowl chain — base + toppings + protein + dressing.
Several logged meals this project (e.g. the soba/tofu/broccoli/edamame/kimchi
bowls) look like they could be Supergreen bowls; worth confirming with Holger
next time one is logged, since these official per-component figures would
replace an estimated whole-dish entry with **label-sourced, uncertainty-0**
per-component ones (portion still needs weighing on the day).

**Caveat: Supergreen only publishes calories + protein.** No carbs, fat, sugar
or fibre are given for any item, signature bowl or component. Those still
need an ingredient-level estimate (or a USDA-generic fallback) if a `.foodnoms`
build wants full macros — treat kcal/protein below as label-sourced, everything
else as still-to-estimate.

Figures are given as published (per stated serving weight) and converted to
per-100g for consistency with the rest of this repo's docs.

## Using this for a logged meal

For a build-your-own bowl, identify base(s) + 4 toppings + protein + dressing
from the photo/description, weigh the portion (before/after), and build the
`.foodnoms` recipe JSON as separate ingredient entries (one per component,
literal `nutrients` block scaled from the per-100g figures above), each at
**uncertainty 0** for kcal/protein (label-sourced) — but note in a `patchNote`
or the entry name that carbs/fat/fibre are absent from the source and are a
separate estimate layered on top, so a mixed-provenance dish doesn't silently
read as fully verified.
