# Nussinow Cooking Times Reference

Reference tables transcribed from *Vegan Under Pressure* by Jill Nussinow.
For use as authoritative source when designing pressure-cooking recipes.

All times assume **natural pressure release** unless otherwise stated.
All quantities given per **1 cup dry** ingredient.

> **Note on photo transcription:** the third numerical column in the Bean Cooking Times table was partially obscured by a bookmark sticker in the source photo. Column 4 data is transcribed but the column header is uncertain. **Please verify and update the column header when you have the book to hand.**

## Low-pressure cooking times

**Nussinow's book does not provide systematic low-pressure cooking times for beans.** The only LP entry in the bean table is for fava beans (8–10 min soaked at LP), and that's a texture/skin choice, not a time-conversion reference.

When LP times are needed (e.g. for the two-phase corn-and-soybean method), they must be extrapolated from HP times. Working multiplier: **LP cook time ≈ 1.5–2× HP cook time** for legumes (based on Q10 thermal kinetics adjusted downward for the fact that both pressures exceed key food-chemistry thresholds). This is approximation, not measurement — track results to refine.
